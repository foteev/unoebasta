# Code of Conduct

unoebasta follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming and patient, respect different views and experience levels, give and accept constructive feedback, and focus on what is best for readers. Harassment, insults and personal attacks are not tolerated.

**Reporting.** To report a problem privately, use GitHub’s [private vulnerability reporting](https://github.com/foteev/unoebasta/security/advisories/new) form (it reaches the maintainers only), or contact a maintainer through their GitHub profile. Reports are handled confidentially.
