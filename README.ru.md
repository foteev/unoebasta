# unoebasta

_You’re the grown-up now. Say yes._ Uno e basta — «одно — и хватит»: ещё одна страница или один рассказ, и всё.

Одна веб-страница для чтения лауреатов «Хьюго», «Небьюлы» и «Локуса»:
- подборка на то время, что у вас есть;
- каталог текстов, которые бесплатно и легально лежат у издателей;
- все премии с 1953 года;
- читалка для своих файлов.

Без приложений и магазинов, без сервера, без аккаунтов и подписок. Всё личное хранится только в браузере.

**Открыть:** https://foteev.github.io/unoebasta/ · English: [README.md](README.md)

Прежние рабочие названия — Fantastic и One More?. Внутренние имена (ключи хранилища `fantastic-*`, база `fantastic`) оставлены, чтобы не потерять данные читателей.

## Ваши данные

- **Где:** в IndexedDB `fantastic` (места чтения, заметки, закладки, «Прочитано», свои ссылки и файлы, отметки удаления) и в localStorage (настройки).
- **Между версиями:** `SCHEMA` — номер формата, сейчас 4. Новая версия несёт шаги `MIGRATIONS[n]`; перед ними сохраняется копия, при ошибке всё возвращается и страница только показывает данные.
- **Синхронизация:** «Моя полка» → «Синхронизация между устройствами» → «Включить», затем «Подключить другое устройство» (QR-код или ссылка-ключ). Полка шифруется на устройстве и хранится зашифрованной на публичных серверах Nostr.
- **На другое устройство:** «Моя полка» → «Данные на этом устройстве» → «Ссылка для другого устройства» (и QR-код). Слияние — `syncMerge`: из двух версий записи остаётся та, у которой новее `mt`.
- Подробно — [docs/data-and-sync.md](docs/data-and-sync.md).

## Как добавить текст к лауреату

Все лауреаты уже есть в `data/awards.json`. Чтобы у произведения появился текст, добавьте запись в `READ` в `src/index.html` по номеру Wikidata:

`Q25349436: { w: 4600, tier: 't2', added: '2026-10-29T21:00:00Z', pub: 'Clarkesworld #100', links: [{ kind: 'full', url: '…', site: 'Clarkesworld' }] }`

- `w` — число слов.
- `tier` — `t1` (CC), `t2` (бесплатно у издателя), `t2us` (общественное достояние США).
- `added` — время в UTC, попадает в «Новое с прошлого визита».

## Ограничения

- Рассказы журналов открываются на сайте журнала: браузер не даёт одному сайту загрузить страницу другого.
- Читалка — для своих файлов: TXT, HTML, EPUB, FB2, FB2.ZIP.
- Данные Wikidata за последний год могут запаздывать.
